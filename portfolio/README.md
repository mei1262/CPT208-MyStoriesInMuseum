# CPT208 Process Portfolio · My Stories in Museums（V-Museum）

本目录为 **CPT208 Human-Centric Computing** 课程 **A3 · My Stories in Museums** 小组的 **过程作品集（Process Portfolio）**：用单页静态站点记录从动机与研究、用户需求、创意与备选、技术实现到评估与反思的完整设计过程，并嵌入背景问卷可视化、概念手稿、系统界面迭代截图与 Alpha 测试摘要。

- **入口文件**：`index.html`（样式 `css/styles.css`，交互 `js/main.js`）
- **离线原型与素材**：`system/`、`system-picture/`、`videoResources/` 等子目录为作业交付支撑材料，可在文中链接打开或本地浏览。

## 本地预览

在本目录下用静态服务器打开即可（任选其一）：

```bash
npx --yes serve .
```

或在资源管理器中双击 `index.html`（部分浏览器对 `file://` 下相对路径有限制，推荐用本地服务器）。
